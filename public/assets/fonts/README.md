# Poppins

Poppins is the shared application font. Normal weights 400, 500, 600, 700 and 800 include Latin and Latin Extended subsets, self-hosted as unchanged WOFF2 files. Typography is defined in `public/typography.css`; controls, dialogs, chat and the standalone game loading screen share the same family. Provider-owned iframe contents are independent.

- CSS source: https://fonts.googleapis.com/css2?family=Poppins:wght@400;500;600;700;800&display=swap
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/poppins/OFL.txt
- License: SIL Open Font License 1.1, included in `OFL-Poppins.txt`.
- Downloaded: 2026-11-14
- No external font requests are made by the application.
