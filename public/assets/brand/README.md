# LuckyLoop wordmark — direction 01

The primary wordmark joins the two lowercase o characters in LuckyLoop into a custom infinity curve. White letterforms and the existing mint accent are intended for dark backgrounds.

- `luckyloop-wordmark.svg`: primary white/mint wordmark, transparent background.
- `luckyloop-wordmark-mono.svg`: monochrome white wordmark.
- `luckyloop-mark.svg`: standalone infinity mark.

Letterforms are outlined from the project's self-hosted Arimo Bold font. The original font and SIL Open Font License are in `../fonts/`. SVG files contain editable paths and have no font or external asset dependencies. The infinity artwork and optical spacing are original to this project.

Previewed at 32px and 48px overall height. These assets are the first design direction and are not yet connected to the application header or startup screen.
