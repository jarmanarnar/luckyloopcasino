# Relax Gaming original artwork and public demos

Reviewed and imported on 2026-11-23. The catalog contains **126 Relax Gaming games: 125 slots and Money Plane (Arcade)**.

## Artwork provenance

Every cover is an existing finished portrait published in [Stake's Relax Gaming catalog](https://stake.com/casino/group/relax-gaming). The original white lower title and Relax footer are embedded in the source image. No cropping, resizing, overlays, redrawn labels, recoloring, recompression or generated artwork was applied. Native bytes were copied to this directory and their SHA-256 hashes matched the downloads.

The 165 rendered game cards were collected through the public catalog's normal Load More interface. Titles were reconciled against the provider's own catalog, not merely the operator's broad Relax category. The 126 included titles are explicitly classified as `Relax Own Games`, and each public launcher configuration independently returned both `studio: Relax Gaming` and the exact official game name. The 39 unmatched cards were excluded; this avoids attributing Relax-distributed partner games to Relax itself.

The operator's observed image URLs contain thumbnail parameters (`w=180&h=236&fit=min&auto=format`). Downloads use the exact same observed asset path without those transformation parameters, preserving the original image. There are 121 native 408×546 images and five native 204×273 images. The smaller sources are Iron Bank 2, Snake Arena 2, Necromancer’s Gate, Pharaoh's Last Wish and Frank's Diner; their native dimensions are declared without upscaling. Source file types are preserved: 101 PNG and 25 JPEG.

All 126 covers were visually reviewed in `artifacts/provider-depth-20261123/relax/full-review-01.jpg` through `full-review-09.jpg`. Contact sheets are review artifacts only; their resizing and labels are not used by the site. `imported-manifest.json` in that directory records each original image URL, observed URL, operator page, official page, dimensions, SHA-256, client check and contact-sheet position.

The five reviewed operator naming variants are Temple Tumble Megaways → Temple Tumble; Bill & Coin 2: Mummy Mischief → Bill & Coin 2; Great Pigsby Megaways → The Great Pigsby Megaways; Kluster Krystals → Kluster Krystals Megaclusters; and Tiger Kingdom → Tiger Kingdom Infinity Reels. Official product identity, launcher game code and original cover were checked together. The catalog retains the provider's official names.

## Demo provenance and verification limits

Each official game page explicitly publishes both desktop and mobile FUN launchers. The imported desktop URL retains `channel=web`, `moneymode=fun`, `jurisdiction=MT` and `partnerid=1`; `demoMobileUrl` retains the page's corresponding `channel=mobile` URL. No expiring session URL is stored.

All 126 desktop launcher responses returned HTTP 200. For each game, the public `getlauncherconfig?gameref=<gameid>` response identified Relax Gaming and the exact official game name. The native client path was derived from the provider's public `launcherlibs/relax.js` and `variant_config.json`, including published variant mappings. All 126 native HTML clients returned HTTP 200 with game scripts. Neither checked launcher nor native client responses supplied X-Frame-Options or Content-Security-Policy headers.

These HTTP checks establish that the published launcher and native game client are available; they do not establish that every game completes loading in every browser or that every downstream service permits framing. The root integration agent separately verified Money Plane's actual embedded FUN interface. No bets, spins or rounds were played for this import. Full response metadata and saved launcher/config/client responses are retained in `artifacts/provider-depth-20261123/relax/audit.json` and `http-evidence/`.
