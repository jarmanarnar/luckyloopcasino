# BGaming approved portrait import — 2026-11-22

30 selected official promo images were copied unchanged from the approved reviews. All are 580×816 WebP portraits with lower white titles and BGAMING at the bottom. Original and copied SHA-256 hashes match. No image was cropped, repainted, relabeled or regenerated.

The demo URL and provider ID for every game were read from its official BGaming page. 13 public FUN launchers returned HTTP 200 and the matching provider identifier in game-launch configuration on the review date. These checks confirm the launch document, not a completed gameplay session. Runtime launch tokens are not stored.

Launcher requests were sampled, not exhaustive: an earlier concurrent pass encountered HTTP 429 rate limiting. Further launcher checks were stopped; remaining entries use demo links explicitly published on their official source pages.

All release dates below appeared consistently in both header and Details on the respective official game page. Dates are source statements, not inferred from file dates.

Formats follow official game types: 21 Slots, two Roulette, one Cards/Blackjack, one Scratch (Scratch Dice). Of the five official Casual games, Space XY uses a timed cash-out/crash mechanic; Limbo XY, Heads and Tails, Plinko and Minesweeper map to Instant Win. Dice Million remains Slots.

Scratch Dice was added after the initial 29-game import using the public promo-pack original reviewed in `artifacts/more-games-review-20261122/bgaming/ScratchDice.webp`. Its published FUN demo is `https://demo.bgaming-network.com/play/ScratchDice/FUN?server=demo`.
