# 3 Oaks Gaming original cover and public demo review

Verified on 2026-11-23. All 106 released games in the official public catalog are included. All are slots, have exact published release dates, playable public demo metadata and matching original 580 x 816 portrait artwork: 104 WebP files, one JPEG and one PNG.

The public launcher sends `Content-Security-Policy: frame-ancestors 'self'`. Coin Volcano was verified in a top-level browser tab; embedding the same URL was correctly refused by the browser. COP COIN therefore shows an explicit **Open demo in new tab** action for this provider, preserves the canonical URL, and never embeds or proxies the restricted page. This does not assert that every game has been individually played.

## Selection and preservation

Each original comes from the game’s Crypto_icons folder (some folders spell the initial C with Cyrillic С). Every cover was visually checked for the correct game/edition, white lower game title and 3 OAKS footer. Files were copied unchanged, preserving source SHA-256 hashes and dimensions. No crops, generated artwork, added titles or repackaging were used.

File signatures were verified for every original. Two source downloads were named .webp but contained a different image format: Dancing Joker is JPEG and Coin Express is PNG. Their local/public extensions are corrected to .jpg and .png; the downloaded bytes and hashes remain unchanged.

The full public promotional root contained 113 entries. Seven aggregate, deactivated or otherwise non-catalog entries were excluded rather than assigned invented demos or release dates. Two folder-name lookalikes were matched explicitly: 777_сoins to 777_coins, and coin_princess_х1000 to coin_princess_x1000.

The launcher URL is the stable endpoint published by each official game detail API. Resolved session URLs are deliberately not stored. Published playable metadata is not a claim that every game has been gameplay-tested in every browser or jurisdiction.

Reproducible metadata, original files and hash manifest are retained in artifacts/newprovider-expansion-20261123/provider-scout2/3oaks-import-manifest.json and 3oaks-audit-results.json. Contact sheets sheet-0 through sheet-5 document the visual review.
