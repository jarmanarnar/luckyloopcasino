# Gamzix original cover review — 2026-11-23

54 games from the official [Gamzix catalog](https://gamzix.com/games/) were selected after visual inspection of their original public promo-pack covers. Each retained cover is a static 580 × 816 WebP with the matching game title in white and the GAMZIX footer. The files are copied byte-for-byte: no cropping, resizing, re-encoding, title replacement or provider overlay.

The catalog currently exposes 59 released records. Five remain excluded from this import: Coin Win: Hold The Spin, Pilot Coin, 3x3: 27 Ways, Pilot Cup, Pilot. The official source labels all 54 included titles as Video Slot, so they belong to Slots. Release dates are from the same official catalog metadata.

Game launch links retain the provider-published `link.gamzix.com` shortlink host and paths. Four official links use HTTP; the same shortlinks were verified over HTTPS (HTTP 200 after redirect) and upgraded to HTTPS for embedded use. Original published URLs are retained below. Resolved CDN links and temporary launch/session parameters are not stored in the game catalog. HTTP launcher checks do not establish runtime playability; browser checks are recorded separately by the integration review.

The artwork files and their SHA-256 hashes below preserve the originals. The file for Triple Joker Catcher was published without an extension; its signature identifies WebP.
